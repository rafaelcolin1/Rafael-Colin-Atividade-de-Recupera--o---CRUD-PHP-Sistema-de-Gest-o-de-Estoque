O sistema será utilizado para controlar os produtos disponíveis no estoque. Cada produto deverá possuir, no mínimo, nome, categoria, descrição, preço, quantidade em estoque e data de validade. 
Desenvolvimento do Sistema 
O sistema deverá implementar um CRUD completo, permitindo cadastrar, visualizar/listar, editar e excluir produtos. 
Todas as operações realizadas no banco de dados deverão obrigatoriamente utilizar Prepared Statements. O projeto também deverá possuir validação dos dados recebidos, tratamento básico de erros e uma estrutura de arquivos organizada. 
Além do funcionamento do sistema, será avaliada a qualidade e organização do código. 
Documentação 
O projeto deverá ser muito bem documentado. No repositório deverá existir um arquivo README.md contendo nome e objetivo do sistema, tecnologias utilizadas, requisitos para execução, instruções de instalação/configuração, estrutura do banco de dados e explicação das principais funcionalidades. 
Também deverá ser criada uma documentação de Caso de Uso, apresentando os atores envolvidos e as ações que podem realizar no sistema. O diagrama poderá ser produzido utilizando uma ferramenta de modelagem e deverá estar disponível dentro do repositório. 
O repositório também deverá conter o arquivo .sql necessário para criação e configuração do banco de dados. 
Versionamento no GitHub 
O projeto deverá ser desenvolvido e versionado utilizando Git e GitHub. Não será considerado um bom versionamento enviar todo o projeto utilizando apenas um único commit.
O histórico deverá demonstrar a evolução do desenvolvimento por meio de commits frequentes e com mensagens claras, por exemplo: Criação da estrutura inicial do projeto, Implementação do cadastro de produtos, Implementação de Prepared Statements, Adição da edição e exclusão de produtos e Documentação do projeto. 
Entrega: 
A entrega será realizada através do link do repositório público no GitHub.
